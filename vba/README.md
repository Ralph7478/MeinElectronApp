# VBA Modules

This directory contains VBA modules for Excel automation and integration.

## Files

- `modFormelZuordnung.bas` - Main formula assignment module with Excel 2019 compliance

## Usage

These VBA modules are designed to be imported into Excel workbooks for automated formula assignment and IBAN processing.

## Compatibility

- Excel 2019 compliant
- Explicit parameter declarations (ByVal/ByRef)
- Late binding for COM objects
